# FairPath Partner

Desktop-first operating platform for FairPath employers, property owners/managers, and reentry organizations.

## Product rules
- FairPath lime: #A8F32C.
- Light + dark mode are first-class requirements across all FairPath software.
- Shared FairPath Core/Supabase backend with FairPath Mobile.
- Partner is operational software, not a marketing site.
- CRM, organizations, teams, roles, auditability, screening/protection contracts, and billing are launch infrastructure.

## Local setup
Copy .env.example to .env.local, add the FairPath Supabase public credentials, run npm install, then npm run dev.

The initial shell uses presentation-only dashboard data. It must be replaced by authenticated Supabase-backed metrics as backend contracts are connected.
